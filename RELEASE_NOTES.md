## 📋 Налаштування перед запуском

### GitHub Secrets
- `DISCORD_WEBHOOK_URL` — Discord webhook для сповіщень
- `STRATZ_API_TOKEN` — Bearer токен від STRATZ API

### GitHub Variables
- `STRATZ_LEAGUE_ID` — ID ліги The International 2026 зі STRATZ
- `SERIES_BEST_OF` — формат серії (2, 3 або 5; за замовчуванням 3)
- `LIQUIPEDIA_USER_AGENT` — User-Agent для Liquipedia API (опціонально)

### Локальний запуск
```powershell
$env:STRATZ_API_TOKEN = "your-token"
$env:STRATZ_LEAGUE_ID = "league-id"
$env:DISCORD_WEBHOOK_URL = "webhook-url"
python main.py
```
